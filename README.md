Cognify: Cognitive Adaptive System for Neurodiverse Students - An AI-Powered Adaptive Learning Platform for Children with Autism Spectrum Disorder (ASD).
Overview of Cognify is that it is a full-stack, AI-powered adaptive learning platform designed to support children with Autism Spectrum Disorder (ASD) through personalized educational experiences. The system adapts learning activities to individual learner performance across eight cognitive domains, using five integrated machine learning models. It incorporates behavioral factors such as fatigue, frustration, and sensory sensitivity to support more responsive learning experiences. Cognify combines machine learning, deep learning, and large language models (LLMs) to provide adaptive difficulty recommendations, personalized task selection, learner performance prediction, and dynamically generated educational activities.
